# Introduction to LangGraph - Course Notebooks

This repository contains the updated notebooks from the course "Introduction to LangGraph", from LangChain Academy, which have been modified to use Ollama Llama3 instead of OpenAI.

## Course Description

**Introduction to LangGraph**: Learn the basics of LangGraph - a framework for building agentic and multi-agent applications. Separate from the LangChain package, LangGraph helps developers add better precision and control into agentic workflows.

**Course URL**: [Introduction to LangGraph](https://academy.langchain.com/courses/intro-to-langgraph)

**Course GitHub URL**: [Introduction to LangGraph - GitHub](https://github.com/langchain-ai/langchain-academy/blob/main/README.md)



## Updates

The original course notebooks use OpenAI. In this repository, I have updated the notebooks to use Ollama Llama3. This change aims to provide a free alternative, as well as a different perspective on implementing the course content and to explore the capabilities of Ollama Llama3 in agentic workflows.

## Repository Structure

- `module-1-introduction/`: Provides an overview of LangGraph concepts and sets the foundation for understanding graph-based AI systems.  
- `module-2-state-and-memory/`: Covers how LangGraph models manage state and memory to handle context effectively in applications.  
- `module-3-ux-and-human-in-the-loop/`: Focuses on designing user experiences for humans to interact with agents.  
- `module-4-building-your-assistant/`: Guides you through creating a multi-agent assistant using LangGraph principles and best practices, to optimize the research process.  
- `module-5-long-term-memory/`: Explores implementing and leveraging long-term memory to create a persistent AI agent, to manage a ToDo list.
